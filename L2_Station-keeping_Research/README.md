This project investigates a new control architecture for spacecraft operating near unstable trajectories in the Earth–Moon system. The research began with a literature review covering libration-point stationkeeping, sampled-data control, event-triggered spacecraft control, and multirate control. That review showed that each of these areas has been studied independently, so simply applying event-triggered control to an Earth–Moon orbit would not constitute a meaningful research contribution. The gap instead appears at the intersection of these ideas: using asynchronous, event-triggered control for a spacecraft whose orbital motion and attitude are physically coupled, with the translational and rotational controllers allowed to update independently.

The goal is to determine whether a spacecraft can track an unstable Earth–Moon libration-point trajectory while updating its control commands only when the dynamics actually require it, rather than continuously or at predetermined fixed intervals. The project uses the Circular Restricted Three-Body Problem (CR3BP) to model the orbital dynamics and develops the control system progressively from conventional continuous feedback to periodic sampled-data control and then event-triggered control. Ultimately, the orbital model will be coupled to the spacecraft’s attitude dynamics so that its orientation affects the direction in which thrust is actually applied. The resulting system will allow orbital and attitude control updates to occur on separate, dynamically determined schedules. The broader research objective is to establish when this architecture remains stable, how well it rejects disturbances, whether pathological infinitely fast triggering can be ruled out, and how much it can reduce control and computational updates without sacrificing acceptable spacecraft performance.
